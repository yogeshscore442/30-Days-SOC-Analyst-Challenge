# 30-Days-SOC-Analyst-Challenge# 🚀 30 Days SOC Analyst Practical Investigation Challenge

A 30-day hands-on cybersecurity challenge focused on developing practical **SOC Analyst and Blue Team skills** through controlled security simulations, log analysis, threat detection, investigation, and incident documentation.

## 🎯 Challenge Objective

The goal of this challenge is to strengthen practical SOC Analyst skills by investigating common cybersecurity alerts and attack scenarios in a controlled lab environment.

Each day focuses on a specific security case and follows a structured investigation process:

- Understand the attack or security scenario
- Simulate the activity in a controlled lab environment
- Collect and analyze security logs
- Detect suspicious activity
- Investigate the available evidence
- Identify relevant security indicators
- Map the activity to MITRE ATT&CK where applicable
- Determine the appropriate response
- Document the investigation in a SOC-style report

## 🔎 Daily Investigation Structure

Each investigation is documented using a consistent SOC workflow:

**1. Scenario**

Understand the security alert or attack technique.

**2. Lab Simulation**

Generate the activity safely within a controlled environment.

**3. Detection**

Identify the relevant logs, events, alerts, or indicators.

**4. Investigation**

Analyze timestamps, accounts, processes, hosts, network activity, and other available evidence.

**5. MITRE ATT&CK Mapping**

Map the observed activity to the relevant MITRE ATT&CK technique where applicable.

**6. Response**

Determine the appropriate containment, remediation, or defensive action.

**7. Documentation**

Create a SOC-style incident report containing the findings, evidence, analysis, and final verdict.
